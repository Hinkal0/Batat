### Введение
 Задачей данного проекта является создание двухмерной roguelike-игры Batat с видом сверху, основанной на таких играх, как Enter the Gungeon и Nuclear Throne, используя язык программирования C++ и графическую библиотеку SFML. В результате разработки должна быть создана законченная игра с процедурно генерируемыми уровнями, боевой системой, врагами с искусственным интеллектом, системой повышения уровня и интерфейсом (меню).
 В игре игрок управляет персонажем, исследующим подземелье, состоящее из нескольких этажей. Каждый этаж представляет собой набор комнат, соединённых коридорами, в которых игрока ожидают враги. Задача игрока - пройти все этажи, победить босса на последнем из них и при этом не погибнуть.
### Постановка задачи
 Игрок перемещается по подземелью клавишами W, A, S, D, а целится и стреляет с помощью мыши: снаряды вылетают в сторону курсора, а камера смещается от персонажа в сторону курсора, позволяя заранее увидеть врагов. Помимо стрельбы у игрока есть удар в ближнем бою, который не наносит урона врагам, но уничтожает или отражает вражеские снаряды, попавшие в зону удара. Таким образом, игрок должен сочетать перемещение, стрельбу и своевременную блокировку снарядов.
 Каждый этаж генерируется заново при каждом забеге с помощью алгоритма двоичного разбиения пространства: игровое поле делится на области, в каждой из них создаётся комната, после чего комнаты последовательно соединяются коридорами. Стены и пол хранятся в виде сетки тайлов, по которой также рассчитываются столкновения персонажей и снарядов; для отрисовки стен выбирается подходящая текстура с учётом соседних клеток. Первая комната этажа является местом появления игрока, в одной из последних размещается выход на следующий этаж, который открывается после уничтожения всех врагов. На последнем этаже вместо выхода находится комната с боссом.
 В комнатах размещаются враги нескольких типов, каждый из которых обладает собственным поведением. Количество и набор врагов зависят от номера этажа и размера комнаты. Враги должны обходить стены, для чего используется поиск пути по сетке тайлов, и атаковать игрока только в пределах прямой видимости. Босс последнего этажа обладает большим запасом здоровья и различными шаблонами атак, а победа над ним завершает забег.
 За убийство врагов игрок получает очки опыта. При накоплении необходимого количества опыта уровень персонажа повышается, и игра предлагает выбрать один из нескольких случайных модификаторов, например увеличение скорости, урона, скорострельности, максимального здоровья или улучшение удара в ближнем бою. Выбранные модификаторы действуют до конца забега.
 В игре реализована перманентная смерть: при потере всего здоровья забег заканчивается, прогресс (этаж, уровень и модификаторы) сбрасывается, а игроку показывается экран смерти с итоговой статистикой. Между забегами сохраняется только лучший результат, который записывается в конфигурационный файл.

 Проект должен быть реализован на языке C++ (версия C++20 и позднее) с использованием графической библиотеки SFML (версия 3.0 и позднее). Он должен быть декомпозирован на файлы для удобства чтения и сборки и собираться с помощью CMake (версия 3.22 и позднее).
 В итоговой версии игры должны быть реализованы: перемещение персонажа с корректной обработкой столкновений со стенами, стрельба снарядами с учётом их столкновения со стенами и персонажами, удар в ближнем бою с блокировкой снарядов, поведение врагов нескольких типов, поиск пути, босс с несколькими фазами, система опыта и модификаторов, генерация этажей и переход между ними.
 Стартовые параметры игры, такие как размер окна, полноэкранный режим и заголовок, а также наибольший результат игрока считываются из конфигурационного файла config.ini при запуске. При отсутствии или повреждении файла должны использоваться значения по умолчанию.
 Игра должна содержать стартовое меню с кнопками начала игры и выхода, подсказками по управлению и отображением лучшего результата. Звуковые эффекты должны сопровождать выстрелы, удар и блокировку снарядов.
